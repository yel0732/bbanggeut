# A501 시연 시나리오

## 1. 시연 목표

다음 제품 흐름을 한 번에 보여주는 것을 목표로 합니다.

```text
로그인
→ 아동 프로필 선택
→ 게임 플레이
→ AI 음성 대화
→ 그림일기 생성
→ 보호자 모드 전환
→ 일기와 성장 리포트 확인
```

권장 영상 길이: 3~5분

## 2. 사전 준비

- 시연용 보호자 계정과 아동 프로필 생성
- Google OAuth 또는 이메일 로그인 상태 확인
- 카메라와 마이크 권한 허용
- 게임 결과 데이터 저장 확인
- Redis, AI Server, Backend readiness 확인
- GMS STT/TTS 및 대화 응답 확인
- 브라우저 확대율 100%, 알림과 개인정보 화면 숨김
- 시연 대사를 메모하되 화면 밖에 배치

### 시연용 계정

일기 및 리포트 데이터가 준비된 제출용 계정입니다.

| 구분 | 이메일 | 비밀번호 | 보호자 PIN |
|---|---|---|---|
| 관리자 시연 계정 | `admin@ssafy.com` | `admin123456!` | `0000` |
| 일반 시연 계정 | `ssafy@ssafy.net` | `ssafy1234!` | `1111` |

시연 영상에서는 비밀번호와 PIN 입력 장면을 잘라내거나 가립니다. 제출 후에는 계정을 삭제하거나 비밀번호와 PIN을 변경합니다.

## 3. 메인 시연 순서

### 3.1 로그인 및 아동 프로필 선택

1. 서비스 메인 화면에 접속합니다.
2. 시연용 보호자 계정으로 로그인합니다.
3. 아동 프로필을 선택합니다.

설명 멘트:

> 보호자는 여러 아동 프로필을 관리할 수 있고, 아이는 자신의 프로필로 게임과 대화를 시작할 수 있습니다.

### 3.2 과일 자르기 게임

1. 게임 선택 화면에서 과일 자르기를 선택합니다.
2. 튜토리얼에서 카메라 기반 손 인식을 보여줍니다.
3. 실제 과일을 자르는 동작을 시연합니다.
4. 게임 결과 화면까지 진행합니다.

설명 멘트:

> 카메라로 손동작을 인식해 아이가 몸을 움직이며 게임할 수 있습니다. 게임 결과는 이후 AI 대화의 문맥으로 연결됩니다.

### 3.3 게임 연계 AI 대화

실제 AI 질문은 생성형이므로 표현이 달라질 수 있습니다. 아이 역할은 아래 핵심 정보가 질문에 맞게 전달되도록 합니다.

```text
AI 예상 질문:
오늘 과일 자르기 했구나! 어떤 순간이 제일 재미있었어?

아이:
마지막에 손으로 수박을 한 번에 잘랐을 때가 제일 재미있었어.

AI 예상 질문:
수박을 한 번에 잘랐구나! 그 순간 기분이 어땠어?

아이:
엄청 신나고 뿌듯했어.

AI 예상 질문:
어떤 점 때문에 그렇게 신났어?

아이:
처음에는 자꾸 놓쳤는데 마지막에는 제대로 잘랐거든.
```

보여주는 기능:

- 게임 이름과 장면을 활용한 질문
- 아이의 말을 짧게 받아 주는 반응
- 사건, 감정, 감정 이유 분리
- 게임 점수만으로 감정을 추측하지 않는 대화

### 3.4 놀이터 일상 대화

게임 이야기에서 일상 이야기로 전환되면 다음 내용을 사용합니다.

```text
AI 예상 질문:
오늘 있었던 다른 일 하나를 말해 줄래?

아이:
오늘 민준이랑 놀이터에서 놀았어.

AI 예상 질문:
놀이터에서 어떤 일이 있었어?

아이:
그네를 타려고 했는데 다른 친구가 타고 있어서 조금 기다렸어.

AI 예상 질문:
그때 마음은 어땠어?

아이:
빨리 타고 싶어서 조금 아쉬웠는데, 나중에 민준이랑 같이 타서 신났어.

AI 예상 질문:
어떤 순간이 제일 기억에 남아?

아이:
민준이랑 누가 더 높이 올라가는지 이야기하면서 탄 게 제일 기억에 남아.
```

AI 역질문 대응 기능도 보여주고 싶다면 다음 장면을 추가합니다.

```text
아이:
너도 그네 타 본 적 있어?

AI 예상 응답:
나는 직접 그네를 타 보지는 못해. 그래도 네 그네 이야기를 듣는 건 좋아!
```

AI는 실제 몸이나 경험이 있다고 꾸미지 않고, 아이 질문에 먼저 답한 뒤 자연스럽게 일기 대화로 돌아갑니다.

### 3.5 그림일기 생성

대화 종료 후 일기 생성 동의를 선택합니다.

예상 내용:

```text
오늘 민준이와 놀이터에서 놀았다.
그네를 타려고 기다릴 때는 조금 아쉬웠다.
나중에 민준이와 함께 그네를 타서 신나고 재미있었다.
누가 더 높이 올라가는지 이야기하며 탄 순간이 기억에 남았다.
```

설명 멘트:

> AI는 아이가 직접 말한 사실만 사용해 짧고 따뜻한 그림일기를 만듭니다. 아이가 말하지 않은 사람이나 사건, 감정은 임의로 추가하지 않습니다.

### 3.6 보호자 모드와 리포트

1. 보호자 모드 진입 절차를 보여줍니다.
2. 오늘 생성된 일기를 확인합니다.
3. 게임 결과와 대화 기반 리포트를 확인합니다.
4. 알림 또는 읽지 않은 리포트 표시가 있다면 함께 보여줍니다.

설명 멘트:

> 보호자는 아이의 게임 결과뿐 아니라 아이가 어떤 일을 겪고 어떻게 느꼈는지 리포트로 확인할 수 있습니다.

## 4. 예외 처리 보조 장면

시간이 허용되면 5~10초 분량으로 사용합니다.

### 아이가 주제를 바꾸고 싶은 경우

```text
아이:
게임 얘기는 말고 오늘 놀이터 이야기하고 싶어.

AI 예상 응답:
그래, 그럼 다른 얘기하자! 오늘 놀이터에서 무슨 일이 있었어?
```

### 아이가 대화를 종료하는 경우

```text
아이:
이제 질문 그만해.

AI:
오늘 이야기 들려줘서 고마워! 다음에 또 이야기하자.
```

## 5. 촬영 체크리스트

- [ ] 시연 계정에 실제 개인정보가 없음
- [ ] 마이크와 카메라 권한 허용
- [ ] 브라우저 개발자 도구와 서버 로그 숨김
- [ ] 게임 결과 저장 확인
- [ ] AI 음성 입력과 출력 볼륨 확인
- [ ] 인터넷 지연에 대비한 재촬영 계획 마련
- [ ] 생성형 질문이 달라져도 말할 핵심 답변 준비
- [ ] 일기 생성 결과 사전 점검
- [ ] 보호자 리포트 생성 시점 확인
- [ ] 영상에 API Key, 이메일, 서버 IP 등 비밀정보가 노출되지 않는지 확인
