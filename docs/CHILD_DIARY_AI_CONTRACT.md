# Child Diary AI Contract

## Purpose

The child diary summarizes exactly one completed conversation for the child who
participated in it. It never combines another conversation, a parent report, or
game database records. A game experience appears only when the child mentioned
it and it was stored in the validated dialogue slots.

## Internal endpoint

```http
POST /internal/v1/child-diaries/summary
```

Request:

```json
{
  "conversationId": "conversation-123",
  "diaryDate": "2026-07-27",
  "topics": [
    {
      "topicType": "GAME",
      "slots": {
        "event": "과일 자르기 게임을 했다",
        "people": [],
        "place": null,
        "emotion": "신났다",
        "emotionReason": "과일을 많이 잘라서",
        "memorableMoment": "마지막 과일을 자른 순간"
      }
    },
    {
      "topicType": "DAILY",
      "slots": {
        "event": "친구와 놀이터에서 놀았다",
        "emotion": "즐거웠다"
      }
    }
  ]
}
```

Success response:

```json
{
  "conversationId": "conversation-123",
  "diaryDate": "2026-07-27",
  "title": "오늘의 일기",
  "lines": [
    "오늘은 과일 자르기 게임을 했다.",
    "과일을 많이 잘라서 신이 났다.",
    "마지막 과일을 자른 순간이 기억에 남았다.",
    "친구와 놀이터에서 놀아서 즐거웠다."
  ],
  "modelVersion": "gpt-5-mini",
  "promptVersion": "child-diary-v7"
}
```

## Invariants

- `title` is always `오늘의 일기` and is not generated by the model.
- `lines` contains three to five non-empty Korean sentences.
- Each line is at most 60 characters including whitespace.
- Only validated slots from the referenced conversation are accepted.
- `topics` contains one or both unique values: `GAME`, `DAILY`.
- With both topics, the result has three to five lines total with at least one
  line per topic, GAME lines first then DAILY lines, without duplication.
- Raw transcripts, child names, access tokens, and game DB records are prohibited.
- The model must not infer facts, diagnoses, advice, comparisons, or future plans.
  It may gently correct a word that is clearly a speech-recognition mishearing
  using the conversation context, but must not add any new person, place, event,
  or emotion that is absent from the input.
- Repeated sentence openings such as `오늘 나는` and `나는` are avoided.
- Event, memorable moment, and emotion are connected without redundant lines.
- Provider timeout, failure, malformed JSON, or invalid line constraints returns 503.
- Invalid requests return 422 with `CHILD_DIARY_REQUEST_INVALID`.

## Runtime configuration

```text
GMS_KEY=<runtime secret>
GMS_CHILD_DIARY_MODEL=gpt-5-mini
GMS_TIMEOUT_SECONDS=10
GMS_MAX_ATTEMPTS=2
```

Secrets must never be committed or logged.
